# Support

This is a small open-source library, not a hosted product. There is no SLA.

| Need             | Where                                                                                          |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| How do I use this? | [`README.md`](./README.md), package READMEs under `packages/`                                |
| Is this a bug?   | [Bug report](https://github.com/gul-labs/flipbook/issues/new?template=bug_report.md)            |
| I want a feature | [Feature request](https://github.com/gul-labs/flipbook/issues/new?template=feature_request.md)  |
| Security         | [`SECURITY.md`](./SECURITY.md) — private advisory, never a public issue                        |
| Conduct          | [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md)                                                   |

Please search existing issues before opening a new one. Include the package name, version, browser/Node version, and a minimal reproduction.
