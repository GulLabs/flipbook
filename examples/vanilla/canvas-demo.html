Canvas / images mode

Public demo of PageFlip.loadFromImages — the API a picture-book reader actually calls. Eight leaf descriptors: a blank leaf, the same 1:2 bitmap under contain, cover and fill, a fractional inset, and one deliberately-missing image so the broken-image glyph is visible. Pixel-probe harness stays at canvas.html; HTML pages at index.html.
